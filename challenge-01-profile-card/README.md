## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/mohamedemad-basha/react-challenges.git
```

Navigate to the project:

```bash
cd challenge-01-profile-card
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm start
```
